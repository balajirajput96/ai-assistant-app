# Release Checklist

- [x] Confirm final Android application identity and semantic version.
- [x] Verify Android target API level is 36 or higher for the planned new-app submission date.
- [x] Replace generated branding with original Orbit icon assets.
- [ ] Review all runtime permissions and remove unused requests.
- [ ] Validate privacy policy, data-safety questionnaire, and third-party AI disclosures.
- [ ] Add and test in-app reporting for offensive AI-generated content.
- [ ] Produce signed Android release artifact through the supported release workflow.
- [ ] Capture authentic device screenshots and prepare store listing assets.
- [x] Run lint, type checks, and unit tests; physical Android smoke test remains required before submission.
- [x] Verify all visible buttons either work or state why they are unavailable.
- [x] Add local Markdown/PDF export with explicit user confirmation and native share-sheet handoff.
- [ ] Confirm source/license inventory and dependency notices.
- [ ] Verify target API and current Google Play policy requirements immediately before submission.
- [ ] Record actual GitHub, CI, backend, and Play Console status in the final verification report.
