# Privacy Model

## Data minimization

Conversation history and preferences are stored locally by default. The assistant sends only the request and limited prior context needed to respond. The client does not transmit microphone audio, files, contacts, location, calendar or camera data unless the user chooses the relevant feature and grants the requested device permission.

## User controls

The product design includes history deletion, local-data clearing, export, a memory/privacy screen, connector revocation and plain-language approval summaries. The initial build does not use advertising, sell data or request access to contacts, location, SMS, calendar or accessibility services.

## Play compliance posture

Google Play requires transparent disclosure of collection, use and sharing; runtime permission requests where available; appropriate security protections; a privacy policy in the store listing and app; and Data safety disclosures. These requirements must be revalidated before the first production submission. [1]
